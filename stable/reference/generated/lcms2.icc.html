lcms2.icc¶

Reading and writing ICC profiles (v2, v4 and v5) in pure NumPy.

  • ICCProfile: a profile’s header and raw tags.

  • ICCSpace: a ~lcms2.spaces.ColorSpace read from a profile.

  • write_icc_bytes: serialize any ~lcms2.spaces.ColorSpace as a profile (also available as ColorSpace.to_icc_profile).

  • ICCParseError, ICCWriteError: reading and writing errors.

write_icc_bytes(colorspace: ColorSpace, *, version: Sequence[int] = (4, 4, 0), rendering_intent: int = 1, grid_size: int | None = None, description: str | None = None, copyright: str = 'No copyright, generated by python-lcms2', force_clut: bool = False, strict: bool = False) → dict[source]¶

Serialize a ColorSpace into ICC profile bytes.

Parameters:

  • colorspace (ColorSpace) – The space to write.

  • version (tuple of int, optional) – (major, minor, bugfix). Default (4, 4, 0).

  • rendering_intent (int, optional) – Header rendering intent. Default 1.

  • grid_size (int, optional) – CLUT grid points per axis for a sampled fallback.

  • description (str, optional) – Profile description and copyright text.

  • copyright (str, optional) – Profile description and copyright text.

  • force_clut (bool, optional) – Always write sampled CLUTs.

  • strict (bool, optional) – Require an exact profile built from traced functions: raise ICCWriteError, naming the operation that could not be traced, instead of falling back to sampled CLUTs (or to probing the functions numerically).

Returns:

dict – {'bytes': bytes, 'method': str, 'notes': list of str}. When the sampled fallback is used, notes says why (naming the untraceable operation).

Raises:

ICCWriteError – If the space cannot be written at all, or with strict=True when only a sampled fallback would be possible.
