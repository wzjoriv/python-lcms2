lcms2.Flag¶

class Flag(*values)[source]¶

Bases: IntFlag

LittleCMS transform flags (cmsFLAGS_*).

Flag.parse accepts an int, a Flag or a string such as "NOOPTIMIZE,BLACKPOINTCOMPENSATION" (separators , | ; or spaces). 8BITS_DEVICELINK is spelled EIGHTBITS_DEVICELINK in Python.

Examples

>>> Flag.parse("gamutcheck|softproofing") == Flag.GAMUTCHECK | Flag.SOFTPROOFING
True
>>> int(Flag.grid_points(33))
2162688
