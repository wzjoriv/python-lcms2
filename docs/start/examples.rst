Examples
========

The `examples folder <https://github.com/wzjoriv/python-lcms2/tree/main/examples>`_ is a numbered learning path
from first conversions to ICC authoring. Each step is a short script (``python examples/01_quick_conversions.py``)
with a notebook beside it that shows every result, so you can read it on GitHub without running anything.

.. list-table::
   :header-rows: 1
   :widths: 10 90

   * - Step
     - Topic
   * - 01
     - Quick conversions: colors, CSS strings, arrays and dtypes
   * - 02
     - ICC profiles: open, inspect, edit, create and save
   * - 03
     - Transforms and images: reuse, alpha, intents, threads
   * - 04
     - Soft proofing and gamut checks
   * - 05
     - Color spaces: OKLab, HSV, PQ and friends
   * - 06
     - Custom color spaces as ICC profiles
   * - 07
     - Colorimetry: color differences, white points, adaptation, CIECAM02
   * - 08
     - Tone curves
   * - 09
     - Colormaps
   * - 10
     - CGATS measurement files
   * - 11
     - Device links and advanced options

See the `examples README <https://github.com/wzjoriv/python-lcms2/blob/main/examples/README.md>`_ for the full table.
