lcms2.Profile¶

class Profile(source: Any = None, *, white_point: Any = None, degrees: int = 2, temperature: float | None = None)[source]¶

Bases: ProfileData

An ICC profile.

Parameters:

  • source (str, os.PathLike, bytes, Profile, colour space or None) – A built-in name (case-insensitive, lenient: "adobe rgb", "display p3", "prophoto"; see builtins()), a path to an .icc/.icm file, raw profile bytes, an object with to_icc_profile() (a ColorSpace) or None for the NULL profile.

  • white_point (str or sequence of float, optional) – For "Lab" only: illuminant name ("D65") or xyY of the Lab white (D50 by default).

  • degrees ({2, 10}) – Observer for illuminant names.

  • temperature (float, optional) – For "Lab" only: white point as a daylight colour temperature in kelvin.

Raises:

  • FileNotFoundError – For a string that is neither a built-in name nor an existing file.

  • CMSError – When the data is not a valid ICC profile.

Examples

>>> import lcms2
>>> p = lcms2.Profile("sRGB")
>>> p.color_space, p.device_class
(<ColorSpaceSignature.RGB: 'RGB'>, <DeviceClass.DISPLAY: 'display'>)
>>> lcms2.Profile("display p3").description
'Display P3'

classmethod from_space(space: Any, strict: bool = False) → Profile[source]¶

An exact profile of a colour space object (anything with to_icc_profile()).

Parameters:

  • space (ColorSpace) – The space; its NumPy to_xyz/from_xyz are traced into an exact profile.

  • strict (bool, optional) – Raise ICCWriteError instead of falling back to sampled lookup tables when the functions cannot be traced (data-dependent branching, float(), random numbers, non-NumPy libraries). Default False.

Raises:

ICCWriteError – With strict=True, naming the operation that prevents an exact profile.

classmethod rgb(white_point: Any = 'D65', primaries: Sequence[Sequence[float]] = ((0.64, 0.33), (0.3, 0.6), (0.15, 0.06)), gamma: Any = 2.2, *, degrees: int = 2, description: str | None = None) → Profile[source]¶

Matrix-shaper RGB profile.

Parameters:

  • white_point (str or sequence of float) – Illuminant name or xyY.

  • primaries (three (x, y) or (x, y, Y) sequences) – Red, green and blue chromaticities.

  • gamma (float, ToneCurve, (type, params) or a sequence of 3 of those) – Transfer function(s) from encoded to linear values.

  • description (str, optional) – Profile description text. Defaults to one naming the white point and gamma, such as "RGB (D65, gamma 2.2)".

Examples

>>> Profile.rgb("D65", gamma=2.2).description
'RGB (D65, gamma 2.2)'
>>> p = Profile.rgb("D65", gamma=2.2, description="my RGB")
>>> p.description, p.is_matrix_shaper
('my RGB', True)
