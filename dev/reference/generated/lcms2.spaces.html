lcms2.spaces¶

Color spaces defined by conversions to and from CIE XYZ (D50).

Every space is a ColorSpace subclass with a ready-to-use instance named in lower case (srgb, oklab, …). Convert with ColorSpace.to:

>>> import numpy as np
>>> from lcms2.spaces import srgb, oklab
>>> srgb.to(oklab, np.array([1.0, 1.0, 1.0]))

ColorSpace.list returns the registered names, and ICCSpace reads a space from an ICC profile. Colorimetry helpers live in lcms2.colorimetry.

class ColorSpace(n_channels: int | None = None, to_xyz: Callable | None = None, from_xyz: Callable | None = None, name: str | None = None, device_domain: tuple | list | None = None)[source]¶

Bases: object

A color space defined by conversions between device values and CIE XYZ (D50).

Define one by subclassing and overriding to_xyz/from_xyz, or by passing to_xyz/from_xyz callables.

Parameters:

  • n_channels (int, optional) – Number of device channels. Defaults to the class attribute, and to the length of device_domain when that lists one pair per channel.

  • to_xyz (callable, optional) – Maps (..., n_channels) device values to (..., 3) XYZ. Required unless a subclass overrides to_xyz.

  • from_xyz (callable, optional) – Maps (..., 3) XYZ to (..., n_channels) device values. Required unless a subclass overrides from_xyz.

  • name (str, optional) – Display name. Defaults to the registered name.

  • device_domain (tuple or list of tuple, optional) – Device value range written to ICC profiles: one (lo, hi) pair shared by every channel, or one pair per channel. Defaults to the class attribute, (0.0, 1.0). Values outside it are clamped in a saved profile. Each end must be finite and lo < hi.

Variables:

  • n_channels (int) – Number of device channels.

  • device_domain (list of tuple) – One (lo, hi) pair per channel, whichever form was given.

  • circular_device_channels (frozenset of int) – Device channels holding an angle; they wrap over their device_domain range (0..360 for degrees).

  • icc_colour_space_signature (bytes or None) – ICC data colour space written to profiles; inferred when None.

Raises:

  • TypeError – If a direction has no implementation, or has both an override and a callable, or the channel count is neither declared nor implied by device_domain.

  • ValueError – If n_channels disagrees with device_domain, a range is invalid, or circular_device_channels names a channel the space does not have.

Examples

>>> import numpy as np
>>> from lcms2.spaces import ColorSpace
>>> gray = ColorSpace(
...     n_channels=1,
...     to_xyz=lambda v: np.repeat(v, 3, axis=-1),
...     from_xyz=lambda xyz: xyz[..., 1:2],
...     name="flat-gray",
... )
>>> gray.to_xyz([0.5]).tolist()
[0.5, 0.5, 0.5]

to_icc_profile(path: str | None = None, *, version: int | tuple = 4, rendering_intent: int = 1, grid_size: int | None = None, description: str | None = None, copyright: str = 'No copyright, generated by python-lcms2', force_clut: bool = False, strict: bool = False) → dict[source]¶

Write this space as an ICC profile.

Parameters:

  • path (str, optional) – File to write the profile to.

  • version (int or tuple of int, optional) – 2, 4, 5 or a published (major, minor, bugfix) revision such as (4, 2, 0). Default 4.

  • rendering_intent (int, optional) – Header rendering intent. Default 1 (relative colorimetric).

  • grid_size (int, optional) – Grid points per axis of sampled lookup tables.

  • description (str, optional) – Profile description text.

  • copyright (str, optional) – Profile copyright text.

  • force_clut (bool, optional) – Always write sampled lookup tables.

  • strict (bool, optional) – Raise ICCWriteError instead of falling back to sampled lookup tables when to_xyz or from_xyz has no exact representation, for example because it branches on values or calls a non-NumPy library. The message names the operation that could not be traced.

Returns:

dict – {'bytes': bytes, 'method': str, 'notes': list of str} where method is the representation written:

  • 'exact_matrix_trc': v2/v4 rXYZ/gXYZ/bXYZ matrix and TRC curves.

  • 'exact_gray_trc': v2/v4 kTRC gray curve.

  • 'exact_lut': v2/v4 A2B0/B2A0 lookup tables holding the curves and linear map exactly.

  • 'exact_mpet': v5 chain of matrix and curve elements.

  • 'exact_calc': v5 calculator elements.

  • 'clut_fallback': sampled lookup tables; notes says why.

Raises:

ICCWriteError – If the version or device_domain is invalid, if to_xyz or from_xyz fails on every input, or with strict=True if there is no exact representation.

get(name: str) → ColorSpace[source]¶

The registered color space called name (case-insensitive; _ and - match), as an instance.

The instance is shared: repeated calls return the same object until another class is registered under that name.

Raises:

KeyError – If no space is registered under name.

Examples

>>> from lcms2.spaces import get
>>> get("OKLab").n_channels
3
