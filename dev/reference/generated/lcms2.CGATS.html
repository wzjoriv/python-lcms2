lcms2.CGATS¶

class CGATS[source]¶

Bases: object

A CGATS.17 / IT8.7 file: one or more tables of named columns and patch rows.

All accessors act on the current table; change it with select() or the table property. Create one with CGATS() (empty), load(), from_bytes() or from_columns().

Examples

>>> import numpy as np
>>> from lcms2.cgats import CGATS
>>> it8 = CGATS.from_columns({"SAMPLE_ID": ["A1", "A2"], "LAB_L": [10.0, 20.0]})
>>> it8.columns
['SAMPLE_ID', 'LAB_L']
>>> it8.column("LAB_L").tolist()
[10.0, 20.0]
>>> CGATS.from_bytes(it8.to_bytes())["A2", "LAB_L"]
20.0
